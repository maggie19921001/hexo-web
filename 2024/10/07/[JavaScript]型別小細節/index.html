JavaScript的型別小細節

型別

  • 原始型別: Number, String, Boolean, Null, Undefined, BigInt, Symbol
  • 物件型別: Object（物件 {}, 陣列 []，函式 function()）

使用 typeof 檢查變數型別

宣告變數

ES6 之後，JavaScript 引入了 let 和 const，取代了早期的 var。

宣告詞 特性 作用域 提升 (Hoisting)
let 可重新賦值 區塊 TDZ（暫時性死區）
const 不可重新賦值 區塊 TDZ（暫時性死區）
var 可重複宣告、賦值 全域/函式 宣告前使用（undefined）

區塊作用域：{} 內有效，通常在函式內部。區塊中可存取全域變數，但不影響全域變數。
**暫時性死區 (TDZ)**：變數在宣告前不可使用，且程式碼會顯示錯誤。

宣告變數的意義

宣告變數可以控制變數的作用範圍，避免全域變數污染（全域變數太多容易出錯）。
特別是用 var 時，幾千行程式碼後可能會讓你忘記前面已經有相同名稱的變數了，可能會不小心重複宣告，還不會顯示錯誤。

另外，const 宣告的物件可以修改內容，因為物件是「傳參考」。也就是說，你可以更改物件內的屬性，但不能把它指向另一個物件。

值的傳遞

  • 原始型別：傳值（複製一份）

    • 如果把一個原始型別的變數賦值給另一個變數，實際上是把那個值「複製」過去。後來即使原變數改變，複製的變數也不會受影響。

  • 物件型別：傳址（傳記憶體位置）

    • 物件型別的變數傳遞的是記憶體位置（參考）。當你改變其中一個變數的內容，另一個也會同步更改，因為它們指向同一個記憶體地址。

詞法作用域（Lexical Scope）是指在程式中，變數的可見範圍是根據程式碼的寫作結構來決定的，而不是根據程式的執行順序或其他因素。

寫程式時，變數在哪裡定義，決定了它可以在哪些地方被存取。這叫做「詞法作用域」，因為變數的作用範圍是在撰寫程式的時候就確定了，而不是在程式執行時動態決定的。
