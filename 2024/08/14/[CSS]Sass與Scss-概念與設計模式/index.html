Sass/Scss 概念與設計模式

SASS和SCSS分別是(Syntactically Awesome Style Sheets)和(Sassy CSS)的縮寫
就是一看就是超讚的樣式和好潮的CSS，非常的直觀XD

SASS和SCSS都是SASS預處理器的語法，能夠有系統的撰寫及管理CSS，提高開發效率和代碼可維護性

語法用軟體編譯成可被瀏覽器讀取的CSS格式

SASS使用縮排來區分物件，相對比較簡潔對，但對新手來說比較容易混亂，且撰寫上和CSS語法有些不同
所以這邊主要就介紹SCSS的用法

SCSS基本介紹

SCSS文件使用.scss副檔名
SCSS是CSS的超集，代表SCSS是CSS的延伸，除了有更多的擴展功能，而開發者也可以將現有的CSS代碼轉換為SCSS。
SCSS支持變數、嵌套、混合和繼承

通用的文字尺寸、顏色就可以使用變數

內建基本調色效果(darkken/lighten)

Live Sass Compiler

Live Sass Compiler 是 VS code 中的延伸模組
可用來編譯並即時更新CSS檔案
安裝後右下角會出現 Watch Sass 眼睛圖示按鈕
按下後會呈現 Watching...，在這個狀態下存檔，就會自動編譯CSS檔案了

建立SASS檔案基本流程

  1. 建立 all.scss 作為主要編譯css檔案
  2. 建立其他(元件) _variable.scss 放置變數
    _reset.scss 初始化CSS
    _main.scss 主要樣式
    _….scss 其他第三方插件
  3. 匯入 all.css @import"variable" @import"reset" @import"main"等等
  4. 編譯轉成 all.css

    檔案名開頭加底線的檔案不會被編譯
    檔案合併成一支CSS也能減少網路請求次數

CSS reset

有CSS reset的好處是可以將各瀏覽器的預設樣式通一

  • meyerweb 全部重置
  • Normalize 保留部分樣式(cmd+S下載)

    下載的檔案如為CSS檔，可直接改副檔名SCSS

設計模式

有許多前人規劃出不同的SASS系統架構，我們可以使用或參考以符合自身專案需求
而其中SMACSS、OOCSS、BEM、RSCSS是比較常見的設計模式

SMACSS

SMACSS是Jonathan Snook所發表的一個CSS/SASS的設計模式
SMACSS 全名是 「Scalable and Modular Architecture for CSS」，意思是可擴展與模組化的設計模式

它將 CSS 分為 Base、Layout、Module、State、Theme 五個層級：

  • Base：全站設定，用來定義 HTML 元素的基本樣式，例如 a, h1 - h6 …
  • Layout：用來定義網頁的版面架構，如 .container、表頭表尾、格線系統等等
  • Module：用來定義獨立、可重複使用的元件，例如 .btn、.nav。
  • State：用來定義元素的狀態，例如 .active、.disabled。
  • Theme：用來定義元素的顏色、字體等主題，例如 .theme-dark、.theme-light。

也可參考Pure.CSS 的base檔案(由yahoo開發)
或下載Customize版本來使用

OOCSS

OOCSS 全名是 「Object Oriented CSS」，意思是「物件導向 CSS」
OOCSS 最主要代表的框架就是 Bootstrap。

而它的主要是兩個概念是：

  • 結構與樣式分離 (Separate structure and skin)
  • 容器與內容分離 (Separate container and content)
