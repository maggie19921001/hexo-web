jQuery 簡介

雖然現在 React、Vue.js 等框架非常流行，但很多舊專案還是用 jQuery，因為它有技術債的問題，可能短期內不會完全被淘汰，所以基礎語法還是得懂。

jQuery 為什麼沒那麼流行了？

  1. 原生 JavaScript 加強：隨著語言進化，像 querySelector 和 fetch 這些原生 API 變得好用，很多 jQuery 功能都可以被取代。
  2. 現代框架的崛起：React、Vue、Angular 這些框架不只讓開發結構化，還提供了更好的狀態管理，而 jQuery 更適合傳統的 DOM 操作，面對現代應用的複雜需求就比較吃力。
  3. 效能問題：當你操作大量 DOM 的時候，jQuery 的效能可能不如現代框架用的虛擬 DOM 技術。
  4. 社群趨勢：開發者和工具都轉向支持現代框架，jQuery 的資源和支持逐漸減少。

常用方法

  • **特效 (Effect)**：
    • .toggle(2000)：2 秒內開啟/收合
    • .fadeToggle()：漸變隱藏/出現
    • .slideToggle()：折疊開合
    • .animate({CSS})：針對有數值的 CSS 做動畫
  • CSS/屬性操作：
    • .addClass('className')：加上樣式
    • .removeClass('className')：移除樣式
    • .toggleClass()：切換樣式
    • .attr('href', 'url')：修改屬性
  • DOM 操作：
    • .html('<tag>')：動態加載 HTML
    • .before('<tag>') / .after('<tag>')：在選取的元素前後插入
    • .prepend('<tag>') / .append('<tag>')：在選取的元素最前/末端插入
    • .remove()：移除 DOM 元素
