JavaScript Tip5:什麼是一級函式？高階函式？

一級函式？

一級函式（First-Class Function）是指函式在語言中被視為「一級公民」的特性。
在 JavaScript 等支持一級函式的語言中，函式可以像變數一樣被使用和操作，例如：

  1. 將函式賦值給變數：函式可以直接被賦值給一個變數，讓變數指向這個函式。

  2. 作為參數傳遞：函式可以被傳遞給另一個函式作為參數，這樣的函式稱為「回呼函式」（callback function）。

  3. 作為回傳值：函式可以作為另一個函式的回傳值，這正是函式工廠的概念。函式能回傳函式，讓結果變得更動態和靈活。

  4. 存入資料結構：函式可以作為陣列或物件的元素來存取，使函式可以在不同資料結構中被組合、調用。

總結

一級函式的特性讓函式可以像數字、字串等資料一樣靈活地使用，這是實現高階函式、回呼函式以及函式工廠的基礎。

高階函式？

高階函式（Higher-Order Function）指的是能夠接收另一個函式作為參數，或是將函式作為回傳值的函式。
相較於一級函式是原有特性，高階函式則是一種運用的手法以達到程式碼的抽象化。

  1. 接受函式作為參數：如果函式接受其他函式作為參數傳入，那麼它就是高階函式。
    常見的例子包括 map、filter、reduce 等。這些函式會接受一個回呼函式（callback function），並在每個元素上應用該函式。
  1. 回傳函式作為結果：如果函式的回傳值是一個函式，那麼它也是高階函式。

  1. 組合或轉換函式：有時候，高階函式會用來組合或轉換其他函式。
    例如，可以使用高階函式來創建條件判斷或執行順序的組合，這在函式式編程中相當常見。

高階函式的重點在於它們賦予了程式碼更高的靈活性和可重複使用性。透過將函式作為參數或回傳值，可以減少重複的程式碼，並使程式更具模組化和可讀性。

量產函式的「函式工廠」？

函式工廠（Function Factory）是一種產生函式的高階函式。
這類函式會根據傳入的參數生成新的函式，以達到重複使用和提高靈活性的效果。
簡單來說，函式工廠就是「製造函式的函式」，可以動態地創建出不同用途的函式。

函式工廠的常見用途是生成具有相似行為的函式，例如設定不同的計算係數、條件或動態的邏輯。這樣可以避免重複程式碼，並讓函式更具參數化的彈性。

函式工廠的重點是當需求變動或需要產生多種相似邏輯時，能透過參數化達到更高的靈活性和模組化，減少重複的程式碼，使程式更具可維護性。

程式碼的抽象化就是把重複的步驟或邏輯抽取出來，寫成通用的函式或模組。
