BEM CSS架構

有時class名稱太多，容易顯得混亂，利用多層次命名，在修改CSS時可以清楚看出正在修改的是哪個部分

BEM（Block, Element, Modifier）是一種前端CSS命名規範，旨在提升CSS的可讀性和可維護性。它透過結構化和語義化的命名方式，使樣式的組織更加清晰且易於擴展。BEM 的核心思想是將網頁的UI組件分解為獨立的區塊（Block）、元素（Element）和修飾符（Modifier）。

BEM 命名規則總結
父區塊 Block：blockＮame
子元素 Element：blockＮame__elementＮame
修飾符 Modifier：blockＮame–modifierName 或 blockName__elementＮame–modifierName

BEM 的優點
提高可讀性：命名規則清晰，使開發者在看到類名時能夠快速了解其用途和位置。
降低樣式沖突的風險：BEM的結構化命名方式可以防止樣式覆蓋問題，尤其在大型項目中。
易於維護：由於樣式是基於模塊化結構，擴展、修改樣式時可以避免對其他部分造成影響。
高重用性：Block是可重用的組件，每個組件內部是獨立的，不會依賴於具體的HTML結構，這使得開發更加靈活。

關於Web APP

Web APP（網頁應用程式，Web Application）是一種運行在網頁瀏覽器中的應用程式，它通過網際網路提供互動功能，並且與傳統的桌面應用程式不同，無需下載或安裝即可使用。Web APP利用標準的網頁技術（如HTML、CSS、JavaScript）來構建，用戶只需在瀏覽器中打開相應的網址即可進行操作。

Web APP 的特點

  • 跨平台性：因為Web APP是基於瀏覽器運行的，它能夠在多個平台（Windows、macOS、Linux，甚至手機的iOS或Android）上運行，只要設備有瀏覽器即可。

  • 無需安裝：不像傳統的桌面應用程式或手機APP，Web APP無需安裝，可以直接通過瀏覽器訪問。

  • 即時更新：開發者可以即時更新應用程式，使用者無需重新下載或安裝更新。所有更新都會在用戶下次打開Web APP時生效。

  • 連接後端伺服器：Web APP通常通過API與後端伺服器交互，以進行資料存儲、數據處理等。例如，常見的Web APP包括電子郵件服務（如Gmail）、社交媒體平台（如Facebook）、在線工具（如Google Docs）等。

  • 響應式設計：許多Web APP採用響應式設計，以適應不同裝置的螢幕大小，從桌面到手機都能夠提供良好的使用體驗。

Web APP 的應用範圍

  • 社交媒體：例如Facebook、Twitter這類平台就是典型的Web APP。
  • 協作工具：如Google Docs、Trello、Slack等，用於團隊合作、文件編輯、任務管理等。
  • 電子商務：線上商店如Amazon、eBay等也屬於Web APP。
  • 線上服務：銀行、政府網站等提供的在線服務也是Web APP的一種。

Web APP 與原生APP的區別

  • 運行平台：
    Web APP基於瀏覽器運行，無需安裝，可以在各種平台上訪問。
    原生APP是專為特定平台開發的（如iOS或Android），需要從應用商店下載並安裝。

  • 開發方式：
    Web APP使用HTML、CSS、JavaScript等網頁技術構建。
    原生APP使用特定平台的編程語言（如Swift、Kotlin）構建。

  • 性能：
    原生APP通常在性能上表現更好，能更直接地訪問設備硬體（如相機、GPS等）。
    Web APP相對於原生APP在性能上可能稍遜一籌，但隨著技術發展，許多Web APP的性能已經有了顯著提升。

總結來說，Web APP 是一種不需要下載和安裝的應用程式，透過網頁瀏覽器即可訪問，並具有跨平台、即時更新等優勢，非常適合需要快速部署和更新的應用場景。
